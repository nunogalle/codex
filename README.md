# Voxel Nexus 3D

Prototipo de juego 3D inspirado en la libertad de construcción de Minecraft, pero con una propuesta propia:

- **Bloques únicos**: `Prismite`, `Mycelux`, `Ferron` y `Nexus`.
- **Exploración aérea** con un dron en tercera persona.
- **Recolección y crafting**: desmonta bloques para obtener recursos y presiona `R` para refinar aleación a partir de Prismite + Ferron.
- **Construcción dinámica**: usa el recurso recolectado para colocar nuevos bloques de forma procedural.

## Controles

- `W A S D`: mover dron
- `Espacio` / `Shift`: subir / bajar
- `Click derecho`: recolectar bloque
- `Click izquierdo`: construir en la cara seleccionada
- `R`: refinar aleación

## Ejecutar

Puedes abrir `index.html` directamente o usar un servidor local:

```bash
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`.
